1. Màu sắc

Bấm nút "Dark mode" ở góc trên để xem trang đổi theme — mọi khối màu đọc trực tiếp từ CSS variable, đúng cách team nên implement trong code thật.

Navy là màu thương hiệu chính — giữ NGUYÊN 1 giá trị #1c2b3a ở cả 2 theme (không đổi theo dark/light, đúng code gốc). Dùng cho sidebar, avatar, nút hành động chính. brand-blue là accent phụ cho link/trạng thái đang hoạt động.
